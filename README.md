## VR-Tranquility ##
This is a personal project, a therapeutic experience that takes place at a tranquil mountaintop Korean Hanok (home). This place serves as a sanctuary for relaxation or just a place you can call home. 

VR is required to run and was tested on a Quest 3. 

Left controller is a Ray Interactor, where a Ray is casted out of the controller and will change color upon collision with an interactable object. Press the Grip to bring the object to your hand. 

### Controls ###
- Left Controller
  - Grip Button
    - There is a Ray Interactor, where a line is cast out of the controller, and it will change color when colliding with an interactable object. Holding the grip button will bring the object to your hand.
  - Joystick
    - Controls your movement.
- Right Controller
  - Grip Button
    - There is a Proximity Interactor, where a small sphere collider will see if it is within range of an object, and if it is, it will grab that object when the grip button is held.
  - Joystick
    - Controls your rotation.
  - A/Primary Button
    - Jump.
